# 🛒 Walmart Sales Data Analysis & Predictive Modeling

## 📌 Project Overview

This project focuses on analyzing Walmart sales data using Data Science and Machine Learning techniques.  
The objective is to clean raw data, perform exploratory data analysis (EDA), visualize business insights, and build predictive models for sales forecasting.

The project was developed as part of a Data Science Internship task assignment.

---

# 🎯 Internship Tasks Covered

## ✅ Task 1: Data Cleaning & Visualization

Performed data preprocessing and cleaning operations on the Walmart dataset.

### Key Activities
- Handled missing values
- Removed duplicate records
- Checked and treated outliers
- Converted data types
- Created visualizations using Python libraries

### Visualizations Created
- Weekly sales trends
- Holiday vs Non-Holiday sales comparison
- Temperature impact on sales
- Fuel price analysis
- Correlation heatmaps
- Store-wise performance charts

### Libraries Used
- Pandas
- NumPy
- Matplotlib
- Seaborn

## ✅ Task 2: Predictive Modeling (Machine Learning)

Built machine learning models to predict weekly sales.

### Algorithms Used

- Random Forest Regressor

### ML Workflow
- Data preprocessing
- Feature selection

- Model training
- Prediction
- Performance evaluation

### Evaluation Metrics

### Performance Visualizations
- Actual vs Predicted Sales

- Error Analysis Charts
